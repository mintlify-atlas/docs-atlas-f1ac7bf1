---
title: "Get started with Fula Storage"
description: "Go from zero to your first upload in minutes. Configure credentials, create a bucket, and transfer files using AWS CLI, Python, JavaScript, or Rust."
---

Fula Storage accepts any S3-compatible client. The only configuration change required is pointing your client at `https://s3.cloud.fx.land` and using your JWT token as the AWS access key ID with a `JWT:` prefix. The AWS secret key is not used and can be set to any non-empty string.

## Prerequisites

Before you begin, you need:

- A JWT access token from `https://auth.fx.land`. See [Authentication](/authentication) for how to obtain one.
- One of the following clients installed: AWS CLI, Python with `boto3`, Node.js with `@aws-sdk/client-s3`, or Rust with `fula-client`.

<Note>
  Replace `your-jwt-token-here` in every example below with your actual JWT token.
</Note>

## Steps

<Steps>
  <Step title="Configure your credentials">
    Each S3 client needs to know your JWT token and the Fula gateway endpoint. Choose your client below.

    <Tabs>
      <Tab title="AWS CLI">
        Add a `[fula]` profile to your AWS credentials file at `~/.aws/credentials`:

        ```ini ~/.aws/credentials
        [fula]
        aws_access_key_id = JWT:your-jwt-token-here
        aws_secret_access_key = not-used
        ```

        Pass `--profile fula` and `--endpoint-url https://s3.cloud.fx.land` to every command.
      </Tab>
      <Tab title="Python (boto3)">
        Create the client inline — no credentials file needed:

        ```python
        import boto3

        jwt_token = "your-jwt-token-here"

        s3 = boto3.client(
            "s3",
            endpoint_url="https://s3.cloud.fx.land",
            aws_access_key_id=f"JWT:{jwt_token}",
            aws_secret_access_key="not-used",
            region_name="us-east-1",
        )
        ```
      </Tab>
      <Tab title="JavaScript (AWS SDK)">
        Configure the `S3Client` with `forcePathStyle: true` to match the Fula gateway's URL format:

        ```javascript
        import { S3Client } from "@aws-sdk/client-s3";

        const jwtToken = "your-jwt-token-here";

        const s3 = new S3Client({
          endpoint: "https://s3.cloud.fx.land",
          region: "us-east-1",
          forcePathStyle: true,
          credentials: {
            accessKeyId: `JWT:${jwtToken}`,
            secretAccessKey: "not-used",
          },
        });
        ```
      </Tab>
      <Tab title="Rust (fula-client)">
        Build a `Config` with your token using the builder API:

        ```rust
        use fula_client::{FulaClient, Config};

        let client = FulaClient::new(
            Config::new("https://s3.cloud.fx.land")
                .with_token("your-jwt-token-here"),
        )?;
        ```
      </Tab>
    </Tabs>
  </Step>

  <Step title="Create a bucket">
    Bucket names must be unique within your account.

    <Tabs>
      <Tab title="AWS CLI">
        ```bash
        aws s3 mb s3://my-bucket \
          --endpoint-url https://s3.cloud.fx.land \
          --profile fula
        ```
      </Tab>
      <Tab title="Python (boto3)">
        ```python
        s3.create_bucket(Bucket="my-bucket")
        ```
      </Tab>
      <Tab title="JavaScript (AWS SDK)">
        ```javascript
        import { CreateBucketCommand } from "@aws-sdk/client-s3";

        await s3.send(new CreateBucketCommand({ Bucket: "my-bucket" }));
        ```
      </Tab>
      <Tab title="Rust (fula-client)">
        ```rust
        client.create_bucket("my-bucket").await?;
        ```
      </Tab>
    </Tabs>
  </Step>

  <Step title="Upload a file">
    <Tabs>
      <Tab title="AWS CLI">
        ```bash
        aws s3 cp file.txt s3://my-bucket/ \
          --endpoint-url https://s3.cloud.fx.land \
          --profile fula
        ```
      </Tab>
      <Tab title="Python (boto3)">
        ```python
        s3.put_object(Bucket="my-bucket", Key="hello.txt", Body=b"Hello World!")
        ```
      </Tab>
      <Tab title="JavaScript (AWS SDK)">
        ```javascript
        import { PutObjectCommand } from "@aws-sdk/client-s3";

        await s3.send(
          new PutObjectCommand({
            Bucket: "my-bucket",
            Key: "hello.txt",
            Body: "Hello World!",
          })
        );
        ```
      </Tab>
      <Tab title="Rust (fula-client)">
        ```rust
        client.put_object("my-bucket", "hello.txt", b"Hello, World!").await?;
        ```
      </Tab>
    </Tabs>

    <Warning>
      Raw S3 tools (AWS CLI, boto3, AWS SDK) upload plaintext. Gateway operators can read uploaded content. For private data, use the [Encrypted Client SDK](/guides/encryption) to encrypt files before they leave your device.
    </Warning>
  </Step>

  <Step title="Download a file">
    <Tabs>
      <Tab title="AWS CLI">
        ```bash
        aws s3 cp s3://my-bucket/file.txt ./downloaded.txt \
          --endpoint-url https://s3.cloud.fx.land \
          --profile fula
        ```
      </Tab>
      <Tab title="Python (boto3)">
        ```python
        response = s3.get_object(Bucket="my-bucket", Key="hello.txt")
        content = response["Body"].read()
        print(content.decode())
        ```
      </Tab>
      <Tab title="JavaScript (AWS SDK)">
        ```javascript
        import { GetObjectCommand } from "@aws-sdk/client-s3";

        const response = await s3.send(
          new GetObjectCommand({ Bucket: "my-bucket", Key: "hello.txt" })
        );
        const text = await response.Body.transformToString();
        console.log(text);
        ```
      </Tab>
      <Tab title="Rust (fula-client)">
        ```rust
        let data = client.get_object("my-bucket", "hello.txt").await?;
        println!("{}", String::from_utf8_lossy(&data));
        ```
      </Tab>
    </Tabs>
  </Step>

  <Step title="List objects">
    <Tabs>
      <Tab title="AWS CLI">
        ```bash
        aws s3 ls s3://my-bucket/ \
          --endpoint-url https://s3.cloud.fx.land \
          --profile fula
        ```
      </Tab>
      <Tab title="Python (boto3)">
        ```python
        response = s3.list_objects_v2(Bucket="my-bucket")
        for obj in response.get("Contents", []):
            print(obj["Key"], obj["Size"])
        ```
      </Tab>
      <Tab title="JavaScript (AWS SDK)">
        ```javascript
        import { ListObjectsV2Command } from "@aws-sdk/client-s3";

        const response = await s3.send(
          new ListObjectsV2Command({ Bucket: "my-bucket" })
        );
        for (const obj of response.Contents ?? []) {
          console.log(obj.Key, obj.Size);
        }
        ```
      </Tab>
      <Tab title="Rust (fula-client)">
        ```rust
        let objects = client.list_objects("my-bucket").await?;
        for obj in objects {
            println!("{}", obj.key);
        }
        ```
      </Tab>
    </Tabs>
  </Step>
</Steps>
